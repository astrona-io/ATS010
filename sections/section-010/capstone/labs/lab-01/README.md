# Applying Policy in Cluster Integration Capstone

Welcome to the Section 010 Capstone. This challenge combines Enforce, Audit, background scanning, autogen, and PolicyExceptions into one integrated task, mirroring how a real platform team rolls policy out gradually across namespaces.

## Launching the Lab
Run the following command in your terminal to boot the kind Kubernetes cluster:
```bash
astrona run --git git@github.com:astrona-io/ATS010.git -c sections/section-010/capstone/labs/lab-01
```
