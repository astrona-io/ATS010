# Background Scan & PolicyException Sandbox

Welcome to the Module 2 targeted practice sandbox. In this lab you'll apply a policy against a cluster that already has a non-compliant Deployment running, observe autogen and background scanning in action, then enable and use a `PolicyException` to carve out a scoped exemption.

## Launching the Lab
Run the following command in your terminal to boot the kind Kubernetes cluster:
```bash
astrona run --git git@github.com:astrona-io/ATS010.git -c sections/section-010/module-02/labs/lab-01
```
