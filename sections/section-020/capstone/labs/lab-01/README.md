# Resource Selection Integration Capstone

Welcome to the Section 020 Capstone. This challenge combines every selection axis from the section — name wildcards, `namespaceSelector`, `objectSelector`, `operations`, and a `subjects`-based exclude — into a single policy, mirroring the kind of layered, precisely-scoped guardrail a real platform team maintains.

## Launching the Lab
Run the following command in your terminal to boot the kind Kubernetes cluster:
```bash
astrona run --git git@github.com:astrona-io/ATS010.git -c sections/section-020/capstone/labs/lab-01
```
