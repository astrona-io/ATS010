# Namespace & Kind Scoped Policy Sandbox

Welcome to the Module 1 targeted practice sandbox. In this lab, you will combine a name-wildcard filter with a dynamic `namespaceSelector` to scope a validate rule to exactly the resources it should — and nothing else.

## Launching the Lab
Run the following command in your terminal to boot the kind Kubernetes cluster:
```bash
astrona run --git git@github.com:astrona-io/ATS010.git -c sections/section-020/module-01/labs/lab-01
```
