# Common Policy Settings Integration Capstone

Welcome to the Section 030 Capstone. This challenge combines webhook resilience settings, retroactive generation into a pre-existing namespace, and priority-ordered mutate rules into one integrated task, mirroring the kind of layered, production-grade policy set a real platform team maintains.

## Launching the Lab
Run the following command in your terminal to boot the kind Kubernetes cluster:
```bash
astrona run --git git@github.com:astrona-io/ATS010.git -c sections/section-030/capstone/labs/lab-01
```
